# Image requests — new calculator tools (July 2026 batch)

Every page below already has a **working placeholder image** (generated by `scripts/generate-new-tools-images.mjs`) so nothing is broken. This file is the manifest for replacing those placeholders with real generated images.

**How to use this file:** copy one prompt at a time into ChatGPT (or your image tool of choice), generate a 1200×630 image, download it, and save it to the exact file path listed. No code changes needed after that — the pages already reference these paths.

**House style for every prompt:** clean modern flat-illustration or soft 3D style, UAE context (Dubai/Abu Dhabi skyline silhouettes, AED dirham notes/coins, diverse expat professionals — South Asian, Filipino, Arab, European mix), brand colors green `#009A44` / dark green `#006630` / navy `#1A2340` / white, no text baked into the image (all text is overlaid by the site), 1200×630 landscape, high detail, no watermarks or logos of real companies/banks.
